# HSBC Pulse 结单积分分析

一个**纯前端**的信用卡结单分析工具：上传汇丰 Pulse 双币信用卡的电子结单 PDF，在浏览器本地解析出每一笔交易，并逐笔算出 RewardCash 积分与有效返现率。

[English](docs/README.en.md) · **在线体验**：<https://hsbc-pulse-rewards-keork2rlvbr.qoder.zone>

## 为什么做这个

汇丰 Pulse 卡的积分是分层叠加的，但结单上只给出一个 `REWARDCASH EARNED` 总额，看不出哪笔交易拿到了多少、哪笔其实没进加成。这个工具把结单拆开，逐笔列出积分构成，方便核对自己刷出来的返现率。

## 功能特性

- **全程本地解析**：PDF 通过 pdf.js 在浏览器内提取文本，不上传文件、不发起任何网络请求
- **双子账户**：同时解析 HKD 与 CNY 两个子账户，自动区分消费、还款与退款
- **逐笔积分**：每笔交易展示积分明细与有效返现率，并汇总年度奖励上限的使用情况
- **交易列表**：商户归一化、支付方式识别，支持按入账日期 / 金额 / 积分 / 费率排序与分页
- **界面**：中英文切换、日间夜间主题、移动端响应式布局

## 快速开始

环境要求：Node.js 20 及以上（开发环境使用 v24）。

```bash
npm install
npm run dev
```

打开 <http://localhost:4400>，点击右上角上传按钮选择结单 PDF 即可。

## 构建与部署

```bash
npm run build
```

项目已启用 Next.js 静态导出，构建产物在 `out/` 目录，可以直接托管到任意静态站点服务（GitHub Pages、Nginx、对象存储等），无需 Node 运行时。

## 测试

```bash
npm test
```

单元测试使用 vitest，覆盖结单文本解析与积分计算两部分。测试所用的结单文本与交易数据均为**合成数据**，不包含任何真实持卡人信息。

## 工作原理

1. **提取文本**：`pdfParser` 用 pdf.js 逐页取出文本层，拼成一整段纯文本。
2. **切词定位**：`statementParser` 按空白切词，用连续的「入账日期 + 交易日期」两个 `DDMON` 词元定位一行交易，向后收集描述词元直到遇到金额词元（金额带 `CR` 后缀表示入账）。
3. **归并尾随标记**：结单排版会把支付方式标记挤到金额之后，解析器会把这些尾随词元并回同一笔交易，从而正确区分普通刷卡与带加成的支付方式。
4. **计算积分**：`rewardCalculator` 按卡片规则逐笔计算基础与加成积分，并累计年度上限，最后在 Dashboard 中渲染汇总与明细。

## 已知限制

- 仅针对汇丰 Pulse 双币卡**电子结单**的版式，其他卡种或纸质结单可能解析失败。
- 解析依赖 PDF 文本层的词元顺序，若银行调整结单模板，需要同步更新解析器。
- 积分结果为本地推算，仅供参考，最终以银行结单为准。

## 隐私

所有解析都在你的浏览器里完成。这个项目没有后端，不收集、不上传、不存储任何结单数据。
